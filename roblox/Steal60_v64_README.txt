Steal60 v64 — ОДИН установочный файл, русский и английский языки внутри игры.

СКАЧИВАНИЕ И УСТАНОВКА
На странице Steal60_v64.rbxmx в GitHub нажмите ↓ Download raw file. Нужен один файл, без ZIP.
Остановите Play. Замените старый установочный пакет v63 в Workspace на Steal60_v64.rbxmx через Insert from File. Оставьте ОДИН установщик. Запустите Play; в Output появятся [Steal60 v64] и [Steal60] Main запущен. Все прежние правки включены.

КНОПКА ru / en
Рядом с нотой в правом верхнем углу добавлена отдельная кнопка 44×44. Она показывает текущий язык: ru — русский, en — английский. Нажатие сразу переключает язык без перезапуска, закрытия меню или сброса прогресса.
По умолчанию используется русский; выбранный язык сохраняется в профиле игрока. Каждый игрок выбирает свой язык независимо. Раннее нажатие до окончания загрузки данных запоминается и применяется после неё. При отключённых Studio DataStore API профиль, как и раньше, временный: постоянное сохранение языка в таком сеансе недоступно.
Переводятся меню, каталог, названия 150 автомобилей и образов, питомцы, краска и тюнинг, описания и покупки, уведомления, обучение и руководство, навигатор, касса, названия районов, дорожные таблички, декоративные магазины и здания, кнопки взаимодействия и заголовки статистики в списке игроков. Надписи, появившиеся позднее при подгрузке района, тоже получают выбранный язык.
Динамические суммы, таймеры, уровни и награды продолжают обновляться. Возврат на ru восстанавливает актуальный русский текст, а не старую сумму. Имена игроков не переводятся. Кнопки и системное меню самой платформы Roblox используют язык приложения Roblox.
Тексты переводятся локально из встроенного словаря без запросов к внешним переводчикам. Внутренние ID, цены, шансы, уровни, сохранения и права на покупки не зависят от выбранного языка.

МУЗЫКА
Значок ноты теперь явно расположен поверх фона кнопки. При выключении он перечёркивается заметной диагональной чертой. Кнопка остаётся компактной, 44×44. Выключение музыки не отключает полицейскую сирену и сигнализацию.
Сами мелодии и их Roblox asset ID сохранены. Три фоновых трека, пять мелодий угона и альтернативы эффектов предварительно загружаются независимо при входе. Недоступный ID больше не задерживает очередь остальных на семь секунд.
Начало взлома переключает музыку по событию HackActive, без ожидания следующего опроса и без повторной загрузки готового трека. Переход от взлома к перевозке сохраняет ту же мелодию. Между композициями короткое плавное смешивание; плейлист избегает немедленного повтора, если доступны другие треки.
Если игрок начал взлом раньше завершения первой загрузки, фон продолжает играть до готовности энергичного трека. Сетевую загрузку нового звука невозможно обещать мгновенной, но длительного последовательного ожидания и искусственной паузы в музыке больше нет.

СОХРАНЕНИЯ И СОВМЕСТИМОСТЬ
Нового сброса монет, усилений или коллекции нет. Studio-хранилище и одноразовый маркер прежнего сброса v62 сохранены. Уровень взлома, XP, алмазы, имущество и текущий сохранённый прогресс остаются прежними. В профиль добавляется только настройка language = ru/en. История чеков и ID покупок не менялись.
Исправление запуска из v63 сохранено. Все предыдущие изменения мира, езды, витрины, мини-игр, NPC, экономики и оформления включены. Настройки реальных Developer Product ID, если вы их меняли в своём проекте, перенесите из своей копии конфигурации как при обычном обновлении пакета.

ПРОВЕРКИ
Из окончательного XML извлечены и скомпилированы все 98 скриптов. Прошли 40 групп проверок в макетах Roblox API: запуск настоящего дерева модулей, восемь скриптов интерфейса, все пять районов, 694 контрольных текста для каждого языка, сравнение с независимым английским отображением, немедленное переключение ru/en, новые вывески, живые суммы, интерактивные подсказки, статистика, сохранение предпочтения, предварительная загрузка музыки, задержанные и запрещённые аудио, отсутствие тишины при холодной загрузке, слои ноты и зачёркивания, уборка обработчиков, а также прежние игровые механики.
Между контрольными языковыми вариантами совпадают все ID 150 автомобилей, косметические asset ID, цены, шансы, параметры внешности и структуры игрового кода. Эти варианты использовались как эталон проверки; пользователю выдаётся ОДИН файл с переключателем.
Roblox Studio/Engine в этой среде недоступна. Реальное звучание, сеть и загрузку аудио в experience, отображение на устройстве и фактическое FPS нужно проверить в Play. Проверки в макете API не являются запуском Roblox Engine.
