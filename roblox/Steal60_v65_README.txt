Steal60 v65 — проверка безопасности и надёжности сохранений.
ОДИН полный установочный файл Steal60_v65.rbxmx, русский/английский переключатель ru/en и прежняя музыка сохранены.

УСТАНОВКА
На странице файла в GitHub нажмите ↓ Download raw file. ZIP не нужен.
Остановите Play. Сохраните копию своего проекта. Замените старый установочный пакет в Workspace через Insert from File на Steal60_v65.rbxmx. Оставьте один установщик.
После Play в Output должны появиться [Steal60 v65] и [Steal60] Main запущен.
Если вы уже настроили настоящие Developer Product/Game Pass ID в своей копии MonetizationConfig, перенесите их в новый пакет перед запуском. В поставляемой конфигурации assetId по-прежнему 0: без реальных ID магазин не принимает реальные платежи.

ЧТО ИСПРАВЛЕНО
1. Сервер принимает команды действий, а цены, владение, требуемый уровень, награды, XP, кассу, алмазы и результаты взлома рассчитывает сам. Клиентского запроса «выдать деньги» или «записать профиль» нет.
2. Единая защита всех серверных RemoteEvent/RemoteFunction обработчиков: допустимые типы/длины/число аргументов, конечные числа, диапазоны управления, частотные ограничения по игроку и команде. GetMenuData/GetSeasonTop тоже ограничены. Неизвестные команды результатов не начисляют наград.
3. Сервер проверяет время удержания ProximityPrompt, расстояние, живого персонажа, готовность профиля, отмену и непрерывное пребывание рядом. Простое принудительное Triggered больше не обходит удержание. В каждый момент учитывается одно удержание игрока.
4. Сервер контролирует перемещение персонажа и машин, владельца, водителя, поколение машины и скорость. Проверка машины вызывается непосредственно перед доставкой, независимо от порядка Heartbeat. Мгновенная доставка телепортом не проходит; проверяются минимальная длительность пути, личная парковка и остановка. Обычная плавная физика водителя сохранена для производительности.
5. Профиль хранится только в Roblox DataStore. Каждая сессия получает уникальный токен, не зависящий от JobId. Запись требует своего токена и корректной ревизии. Старый сервер не может перезаписать новую сессию после истечения аренды. Блокировка обновляется при сохранениях; при длительной невозможности подтвердить сессию действия блокируются и игроку предлагается перезайти.
6. Автосохранение каждые 30 секунд. Изменения денег и ключевые действия дополнительно планируют объединённую запись примерно через 6 секунд; бесплатные переключения внешности не создают запись на каждый клик. Платные косметические покупки/VIP и Robux-чеки используют немедленную запись. Есть повторные попытки с увеличением задержки при сбоях DataStore.
7. Две чередующиеся резервные записи в отдельном серверном DataStore с ревизиями. При повреждении/отсутствии основного профиля выбирается самая новая корректная резервная запись. Существующее повреждённое сохранение без подходящей резервной копии не заменяется нулевым. Ошибка чтения также не считается новым игроком.
8. Выход игрока сохраняет данные и освобождает токен. Неудачная запись не удаляет профиль из памяти: сервер повторяет её. Выход во время первоначальной загрузки тоже освобождает полученную сессию. При штатном закрытии сервера финальные сохранения выполняются параллельно, с общим пределом ожидания 25 секунд. Временные Studio-профили не удерживают остановку сервера.
9. Robux-алмазы выдаются только через серверный MarketplaceService.ProcessReceipt с известным Product ID. PurchaseId сохраняется в профиле; повторные вызовы и потерянные ответы записи не дают повторную награду. PurchaseGranted возвращается после подтверждения основной и резервной записи. Свежий игровой профиль не заменяется старым снимком после обработки чека. Покупка пасса дополнительно проверяет владение через Roblox API.
10. Возврат денег при неудачной косметической покупке возвращает только сумму этой покупки, сохраняя параллельно заработанные монеты и полученные по чеку алмазы.
11. Для краж между игроками добавлен долговечный журнал списания и идемпотентный входящий перевод: повторная попытка или переподключение не выплачивает награду дважды. Личный cooldown и защита кассы цели сохраняются. Счётчик краж и процентный бонус награды учитываются на сервере. Сохраняется прежний предел потери кассы при PvP; полицейский штраф отдельно остаётся 5% кассы без потолка 2500.
12. В сезонный рейтинг уходит сохранённый сервером валовой заработок. Расходы, штрафы и перевод денег из кассы в кошелёк не уменьшают и не удваивают его.
13. Автоматическая выдача тестовых алмазов ограничена Studio. На опубликованных серверах новый бесплатный грант не выдаётся, даже аккаунту разработчика. Уже имеющиеся алмазы и покупки сохраняются.

СОВМЕСТИМОСТЬ
Нового сброса прогресса нет. Live-хранилище Steal60_PlayerData_v1, Studio-хранилище Steal60_PlayerData_Studio_v62 и прежний одноразовый маркер studioFreshStartV62 сохранены. Прежнее правило отдельного тестового сброса v62 не расширено. Уровень/XP взлома, существующие алмазы, покупки, предметы, машины, внешность и язык не удаляются.
Новые резервные хранилища: <имя основного DataStore>_Recovery_v65. Они независимы для Studio и опубликованной игры. Первая резервная запись появляется после успешного сохранения v65; отсутствующую историю резервов за старые версии восстановить задним числом нельзя.
Экономические цены/шансы, 150 машин, одновременно устанавливаемый тюнинг, оформление, NPC, музыка, эффект ноты и переключатель языка сохранены.

ПРОВЕРКИ СБОРКИ
100 скриптов окончательного XML компилируются. 43 группы проверок в макетах Roblox API прошли.
Новые проверки включают 53 сценария надёжного профиля, 135 проверок входящих команд/перемещения/удержания и 33 проверки настоящего DataService вместе с реальными ProfileStore и MonetizationService. Проверены повторные/неопределённые платежи, смена владельца сессии, одновременные покупки и заработок, повреждённые профили, резервное восстановление, сбой на выходе, выход в процессе загрузки, повторный вход, периодическое сохранение, штатное закрытие и PvP-переводы.
Дополнительно проверена доставка, включая проверку телепорта в том же кадре до Heartbeat, а также прежние механики, UI, запуск настоящего дерева модулей и всех восьми клиентских скриптов, все районы, 694 переводимых текста и музыка.
Roblox Studio/Engine здесь недоступна. Это проверки кода и макетов API, а не запуск настоящего сервера Roblox или замер FPS/задержек.

ПЕРЕД ПУБЛИЧНЫМ РЕЛИЗОМ
В приватной опубликованной игре с двумя аккаунтами:
- Настройте реальные Developer Product ID/Game Pass ID и фактические цены в Creator Hub. Для магазина из конфигурации рекомендовано 1500 алмазов за 500 Robux; реальная цена задаётся в Roblox, а не только текстом меню.
- Проверьте небольшой настоящий платёж: правильный пакет алмазов, сохранение после повторного входа, отсутствие повторной выдачи. Studio-имитация платежа этого не подтверждает.
- Заработайте/потратьте монеты, улучшите предмет, смените язык и витрину. Подождите не менее 35 секунд, выйдите и войдите. Сравните кассу, кошелёк, XP, покупки и настройки.
- Проверьте обычное закрытие тестового сервера и повторный вход на новый сервер. Проверьте кражу между двумя игроками, награду и cooldown после переподключения.
- На планшете и компьютере проверьте обычный бег/прыжки, все удержания, взлом, посадку, езду, доставку после выхода из машины, арест и возврат автомобиля. При слабой сети посмотрите, нет ли ошибочных возвратов позиции; защита не использует автоматические баны.
- Проверьте Output, максимальное число игроков 8, доступность музыкальных/аватарных assets и права на их использование в этом experience.
Studio Access to API Services требуется только для постоянных данных во время Studio-теста; Studio использует отдельное хранилище. При недоступных API тестовый профиль временный, о чём пишет Output. Это не подтверждение работы опубликованных сохранений.

ОГРАНИЧЕНИЯ
Нельзя обещать абсолютную защиту от всех эксплойтов или нулевую потерю ещё не записанных изменений при аварийном завершении процесса/сбое Roblox. Последний подтверждённый основной/резервный снимок сохраняется; небольшое окно между записями остаётся. Резерв в другом DataStore не является независимым от Roblox провайдером. Автоматизацию правильных действий и ботов одними серверными проверками полностью исключить нельзя. Не публикуйте игру как проверенную в реальном Engine до завершения приватного теста выше.

English: one full installer with ru/en. This release adds server command validation, rate limits, prompt-hold and movement checks, fenced DataStore sessions, rotating recovery records, bounded autosave/exit retries, idempotent Marketplace receipts and PvP transfers. Existing progression and economic settings are preserved. Run the private published-game save/payment/device checks before release; real Roblox Engine testing was not available here.
