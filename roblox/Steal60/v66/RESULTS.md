## Воспроизведение

```sh
python3 tests/validate.py \
  --luau /path/to/luau \
  --compiler /path/to/luau-compile \
  --baseline /path/to/Steal60_v65.rbxmx
python3 tests/economy_report.py --luau /path/to/luau
```

Валидатор извлекает исходники из **конечного XML** во временную папку. `--baseline` необязателен, без него сравнение с v65 пропускается. `--integration-only` запускает отдельную доставку. `atelier_regressions.luau` выполняет пять категорий реального ателье с сеткой, границами/пересечениями и мастерством; `menu_regressions.luau` выполняет полные вкладки и watcher/геометрию пяти модальных окон; `runtime_regressions.luau` выполняет мини-игру/отмену/аудио/NPC-контракты, `upgrade_choices.luau` — новые покупки и карточки; `visual_regressions.luau` и `economy_cosmetics.luau` — геометрию и косметику. `roblox_mock.luau` — ограниченный API-двойник, не движок. Контроль памяти воспроизводится заменой только двух Source (HackService/ClientMain) на версии из `git show 3e234046:roblox/Steal60/v66/Steal60_v66.rbxmx` и запуском того же валидатора с `--xml` для отдельной копии. Реальные деньги/Marketplace не запрашивались.

## Требует настоящей Studio / Not run in Roblox Engine

**Roblox Studio/Engine в этой Linux-среде отсутствует.** До публикации Experience проверить:

1. Импорт/Output; быстрый ввод памяти, тройное нажатие, закрытие крестиком/Escape/B и немедленный взлом другой машины, возврат фоновой музыки, удаление цели/респавн. Не должно быть новых ошибок API или зависших BUSY.
2. RU/EN 10+ раз с открытыми обычными/VIP-меню, тюнингом, справочником и новым районом. На телефоне/desktop проверить почти полноэкранные окна, колонки/превью ателье и переход к мастерству, затем пять карточек с двумя валютами у каждой прибавки, отсутствие обрезаний/перекрытий, читаемость полок/рейтинга и положение руководства.
3. Купить рабочего, повысить мастерство, вернуться к своему аватару и перезайти: бонус/уровень сохраняются. Осмотреть причёску, заметный полупрозрачный плечевой шлейф и восходящие завихрения в покое/ходьбе/машине, всех наземных питомцев с разными аватарами и тюнингом.
4. Прослушать двигатель `13114759`: цокот после фильтра/повтора может требовать реальной правки звукового ассета. Прослушать единственную сирену `156667202` при полиции: умеренная, без крика. Проверить разрешения музыкальных ID для вашего Place. Эти ID здесь не проверены прослушиванием или через Roblox-контекст; сетевые запросы к метаданным Roblox недоступны.
5. Осмотреть углы перекрёстков и все пять тем, проехать поперёк, проверить здания/дворы/полицейского/ремонт, одежду и поворот NPC к каждому из двух игроков. Проверить живую физику конусов, крыши/стёкла/тюнинг.
6. Два игрока разного навыка: районы 6–8, машины 25–30/сложная цель, реальная проверка навыка и полицейский возврат, выгрузка 8 с, золотая надпись около секунды/25 с. Проверить геймпад, PvP 120/300 с, доставку и обучение.
7. В Studio с API проверить однократный личный сброс и настройки между сеансами. В разрешённом тестовом Experience отдельно проверить настоящий DataStore/lease/backup/завершение сервера и ProcessReceipt. Атомарность и сохранение при реальном внешнем сбое не доказаны mock-тестами.

English: all automated checks above ran against this final XML in official Luau with explicit API doubles. Rendering, listening, physical replication, actual input devices, live DataStore, Marketplace and external asset permissions remain untested. This branch publishes the installer, not the Roblox Experience.
