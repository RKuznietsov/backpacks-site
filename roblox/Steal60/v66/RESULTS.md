# Проверка Steal60 v66 / Validation

Дата: 2026-11-01. Новое: награда на экране следует за машиной, полный кузов сбивает конусы, прозрачные высокие границы и морской горизонт. Добавлены общие модели торговцев, сохранение прокрутки, награда за конусы и баннер 1,5/10 секунд. Проверяется текущая сборка из приложенного v65, включая индивидуальные подписи машин, оба API штатного PlayerModule, первую посадку с частично загруженным rig и выравнивание слева сверху. Опора выставки, восстановление четырёх взломов и полноценная голова в портрете сохранены. Предыдущие окна, сетка, экономика, доставка и оформление сохранены. Результаты потерянной среды v66 не использовались.

## Воспроизведение

```sh
python3 tests/validate.py \
  --luau /path/to/luau \
  --compiler /path/to/luau-compile \
  --baseline /path/to/Steal60_v65.rbxmx
python3 tests/economy_report.py --luau /path/to/luau
```

Валидатор извлекает исходники из **конечного XML** во временную папку. `--baseline` необязателен, без него сравнение с v65 пропускается. `--integration-only` запускает отдельную доставку. `mobile_driving.luau` выполняет оба API PlayerModule, частичный rig, touch→сиденье→проверенный владелец→команды движения и выставку; `vehicle_labels.luau` — CarFactory, локальные подписи для двух клиентов, позднюю подгрузку, пул и RU/EN; `shop_cones.luau` — модели торговцев, сохранение прокрутки всех магазинов, следование монетки за машиной на скорости и расписание баннера; `cone_contacts.luau` — передний/задний/боковой контакт полного кузова; `ocean_rewards.luau` — размещение награды, морской горизонт и невидимые границы; `avatar_preview.luau` — современный rig/голову/портрет; `atelier_regressions.luau` выполняет пять категорий реального ателье с сеткой, границами/пересечениями и мастерством; `menu_regressions.luau` выполняет полные вкладки и watcher/геометрию пяти модальных окон; `runtime_regressions.luau` выполняет мини-игру/отмену/аудио/NPC-контракты, `upgrade_choices.luau` — новые покупки и карточки; `visual_regressions.luau` и `economy_cosmetics.luau` — геометрию и косметику. `roblox_mock.luau` — ограниченный API-двойник, не движок. Контроль памяти воспроизводится заменой только двух Source (HackService/ClientMain) на версии из `git show 3e234046:roblox/Steal60/v66/Steal60_v66.rbxmx` и запуском того же валидатора с `--xml` для отдельной копии. Реальные деньги/Marketplace не запрашивались.

**Roblox Studio/Engine в этой Linux-среде отсутствует.** До публикации Experience проверить:

1. Проверить реальное ощущение сцепления/поворота и вращение всех колёс. Осмотреть опору машин на площадках.
